Проблема

Бренды тратят миллионы на кампании «пробеги N км — получи награду». Но до 30% активности — фейки: GPS-спуфинг, эмуляторы, боты. Деньги уходят не спортсменам, а скриптам. Существующие платформы не дают бренду способа проверить данные.

Решение: PSS-1 сигнал

Каждая тренировка превращается в верифицируемый сигнал:

{
  "signal_id": "20261006_a1b2c3d4",
  "activity": { "distance_m": 10500, "duration_sec": 3200 },
  "biometrics": { "avg_heart_rate_bpm": 162, "vo2max_estimated": 48.5 },
  "quality": { "score": 92, "confidence": "high" },
  "athlete": { "human_verification": { "provider": "worldid", "is_verified": true } },
  "proof": { "signature_ed25519": "hex:...", "gps_track_hash": "sha256:..." }
}

Любая сторона может проверить подпись и целостность данных без доверия к узлу.

Как это работает

1

Атлет бежит

Часы/датчики пишут GPS-трек и пульс. Данные проходят sanity-фильтры и получают Quality Score (0–100).

2

Узел подписывает

DePIN-узел формирует PSS-1 сигнал и подписывает его Ed25519. Привязка к человеку — через proof-of-humanity.

3

Бренд верифицирует

Webhook получает сигнал. Подпись проверяется на стороне бренда. Репутация узла — on-chain.

4

Награда выдаётся

Только сигналы, прошедшие правила кампании (дистанция, quality, human proof), получают награду.
